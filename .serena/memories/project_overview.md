Project opencv_5g: C++20 vision/control app with ONNX-based cone detection and related modules. Key targets in src/: main.cpp (cone detection GUI), guided_main.cpp, trace.cpp plus helpers; src/car/ holds detection modules/tests. Assets: config/config.json for runtime tuning; model/ ONNX weights; img/ sample media; lib/onnxruntime-win-x64-1.23.2 for runtime. Built with CMake; executables run from build/ (Windows .exe). Uses OpenCV, spdlog, ONNX Runtime. Coding style: Allman braces, 4-space indent, camelCase for funcs/vars, PascalCase for types; prefer const refs, spdlog over cout, config-driven behavior. Security: handle missing files gracefully, avoid blocking in real-time loops.
